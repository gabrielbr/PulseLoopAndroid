# Graphic Design Fundamentals

A working rulebook distilled from a full graphic design curriculum. Use it on every new design project (branding, print, editorial, packaging, web/UI, motion, posters, decks) to make decisions grounded in principles rather than taste alone, and to critique work before delivering it.

This skill is a principles layer. It does not replace a project's design system or frontend skill; it informs the decisions those make. When a project has its own brand guidelines or design system, those win on specifics (colors, fonts, spacing); these fundamentals still govern how they are applied.

## How to use this skill

1. Run the **Process** (section 1) before designing anything.
2. Apply the **Foundations** (section 2) and **Typography / Color / Layout** rules (sections 3 to 5) to every output.
3. Add the **domain section** that matches the deliverable (sections 6 to 11).
4. Before delivering, run the **Critique checklist** (section 13) and fix what fails.
5. When explaining choices to the user, name the principle behind them (e.g. "increased contrast in scale to fix hierarchy").

## 1. Process (methodology)

Follow a structured design process (Munari / Löbach / Bonsiepe tradition; Double Diamond):

1. **Briefing** - Who is it for, what must it achieve, where will it live (medium, size, context), constraints (budget, brand, deadline, tech).
2. **Problem definition** - Restate the problem in one sentence. List requirements and success criteria.
3. **Research** - Audience, competitors/references, existing brand assets, context of use.
4. **Ideation** - Generate several directions before committing (mind maps, SCAMPER, morphological analysis). Never present only the first idea when exploring.
5. **Development** - Refine one or two directions; test at real size and in real context.
6. **Evaluation** - Check against the brief and the critique checklist; test with users when it's a product.
7. **Implementation** - Production-ready files, specs, guidelines.

If the brief is missing critical information (audience, medium, goal), ask before designing.

## 2. Foundations

**Elements**: point, line, shape, plane, texture, value, color, space.

**Principles** - every layout must answer each:
- **Hierarchy**: one clear entry point. Rank content (1st, 2nd, 3rd read) and express rank through size, weight, color, position and space. If everything is emphasized, nothing is.
- **Contrast**: differences must be decisive (size, weight, color, density). Timid contrast reads as a mistake.
- **Balance**: symmetrical (formal, stable) or asymmetrical (dynamic). Asymmetry needs deliberate counterweights.
- **Alignment**: every element aligns to something. Prefer one strong alignment axis over several weak ones.
- **Proximity**: related items close together, unrelated items apart. Spacing communicates grouping before anything else.
- **Repetition / consistency**: repeat styles, spacing and treatments to build a system.
- **Rhythm**: vary scale and spacing in patterns to guide pacing.
- **Whitespace**: an active element, not leftover space. Generous margins signal quality.
- **Unity**: the piece should feel like one thing, not a collage.

**Gestalt**: proximity, similarity, closure, continuity, figure-ground, common region. Use them deliberately for grouping and for logo/symbol design.

**Visual weight**: larger, darker, more saturated, more complex, and isolated elements feel heavier. Balance accordingly.

## 3. Typography

**Selection**
- Default to 1 typeface family, maximum 2 (plus an optional mono or display). Pair by contrast (serif + sans, or geometric + humanist), never two similar fonts.
- Choose type for its voice and its job: humanist = warm/readable, geometric = modern/clean, grotesque = neutral, transitional/old-style serif = editorial/literary, slab = sturdy, display = headlines only.
- Check language support (accents, e.g. Portuguese), weights available, and licensing.

**Scale**
- Use a modular scale (ratio ~1.2 to 1.333 for UI/dense content; 1.414 to 1.618 for expressive/editorial).
- Limit the number of sizes; each size should have a role.

**Text setting (micro-typography)**
- Body size: ~16 to 18px on screen; ~9 to 11pt in print.
- Line length: 45 to 75 characters (ideal ~66).
- Leading: 1.4 to 1.6 for body text; 1.0 to 1.25 for headlines.
- Tighten tracking slightly on large headlines; add tracking to all-caps and small labels.
- Kern display type manually (logos, headlines).
- Left-aligned, ragged right by default. Justify only with good hyphenation. Avoid centered text for more than 3 lines.
- Avoid widows, orphans, rivers, and bad rag shapes.
- Use real typographic characters: curly quotes, proper dashes (en/em), ellipsis, true small caps, no faux bold/italic.
- Never stretch or distort type.

**Hierarchy with type**: vary as few properties as needed (size OR weight OR color) and make each change clear.

## 4. Color

- Start with value (light/dark) structure; a design should work in grayscale.
- Build palettes with intent: complementary (tension), analogous (harmony), triadic (vibrant), monochromatic (calm).
- Proportion rule of thumb: ~60% dominant, 30% secondary, 10% accent. The accent is for what matters most (CTAs, key data).
- Limit the palette: 1 to 2 brand colors + neutrals + semantic colors (success, warning, error) in UI.
- Consider psychology and cultural meaning for the audience and market.
- **Medium**: RGB/hex for screen; CMYK/Pantone for print. Check gamut; vibrant RGB colors may dull in CMYK.
- **Accessibility**: text contrast at least 4.5:1 (normal text) and 3:1 (large text and UI elements) per WCAG. Never use color as the only carrier of meaning.
- Define dark mode deliberately; don't just invert.

## 5. Layout and grids

- Start every layout with a grid: margins, columns, gutters, baseline. Swiss/International Style (Müller-Brockmann) is the reference.
- Common grids: 12-column (web), 4-column (mobile), 2 to 6 columns or modular (print/editorial).
- Use a spacing system (e.g. 4 or 8 pt base) and only use values from it.
- Break the grid only on purpose, and only once you've established it.
- Respect reading patterns: Z-pattern for sparse layouts, F-pattern for text-heavy screens.
- Group with space first, then with lines/boxes only if needed.

## 6. Visual identity / branding

- Start with strategy: positioning, audience, personality (3 to 5 adjectives), competitors.
- Logo types: symbol, logotype, combination mark, monogram, emblem. Choose for the brand's use cases.
- A logo must work: at small size (~16px favicon / 1cm print), in one color, in black and white, reversed on dark, and on photos.
- Build a system, not just a logo: logo + clear space + minimum size + color palette + typography + imagery style + graphic elements + tone of voice.
- Deliver guidelines with do's and don'ts and real applications (stationery, social, signage, digital).
- Prefer simplicity and distinctiveness over trends.

## 7. Editorial design

- Establish a grid and master pages; keep consistent margins (inner/gutter margins account for binding).
- Define a clear typographic system: headline, deck, body, captions, pull quotes, folios, running heads.
- Pace the publication: alternate dense and open spreads; think in spreads, not single pages.
- Image-text relationships: images should be cropped with intent and aligned to the grid.
- Covers sell: one dominant element, legible title at thumbnail size.

## 8. Packaging

- Design on the dieline; confirm structure, folds, glue areas and material.
- Shelf impact: recognizable from 2 to 3 meters; the brand and product type must read instantly.
- Information hierarchy: brand > product name > variant/flavor > key benefit > mandatory info.
- Include required legal/regulatory info (ingredients, barcode, weight, local regulations).
- Mock up in 3D and check every face.

## 9. Advertising, posters and campaigns

- One big idea per piece; the concept comes before the layout.
- Image and copy should work together (each adds meaning the other doesn't repeat).
- Posters/OOH: readable in 3 seconds and from a distance; few words, huge hierarchy.
- Campaigns: consistent system across formats, adapted to each channel's specs.

## 10. Signage, wayfinding and information design

- Pictograms: consistent stroke, grid and style across the whole set (ISO/AIGA conventions where possible).
- Wayfinding: information at decision points, consistent placement, legible from viewing distance (size type for distance).
- Infographics/data viz: one key message per chart, label directly, remove chartjunk, start bar axes at zero, use color to highlight not decorate.

## 11. Digital: UI, UX, web and motion

**UX**
- Start from users: research, personas, journey maps, user flows, information architecture.
- Wireframe before visual design; prototype to test.
- Apply Nielsen's 10 usability heuristics (visibility of status, match real world, user control, consistency, error prevention, recognition over recall, flexibility, minimalist design, error recovery, help).

**UI**
- Build with components and states (default, hover, focus, active, disabled, loading, empty, error).
- Touch targets at least 44x44px; adequate spacing between targets.
- Visible focus states; keyboard navigable; semantic structure.
- Responsive by design: define breakpoints and how the grid reflows; design mobile-first when the audience is mobile.
- Consistent iconography (one set, one style, one stroke weight).

**Motion**
- Animation principles: timing, easing, anticipation, follow-through, staging.
- UI motion should be purposeful (feedback, orientation, continuity), typically ~150 to 300ms; ease-out for entering, ease-in for leaving.
- Respect reduced-motion preferences.
- Kinetic type and logo animation: storyboard first.

## 12. Imagery and production

**Imagery**
- Photography: consistent lighting, color grade and art direction across a project.
- Crop with intent (rule of thirds, leading lines, faces with looking room).
- Illustration: one consistent style per project.
- Read images semiotically: check denotation and connotation (what it shows vs. what it implies) for the audience.

**Production (print)**
- 300 dpi at final size for raster images; vector for logos and type.
- CMYK with the correct color profile; rich black for large areas, 100K for small text.
- Add bleed (typically 3mm) and keep content inside the safe area.
- Outline or embed fonts; export print-ready PDF (PDF/X).

**Production (screen)**
- Export in appropriate formats (SVG for icons/logos, WebP/PNG/JPG for images), optimized for size; provide @2x assets when needed.

## 13. Critique checklist (run before delivering)

Answer each honestly; fix anything that fails.

1. **Brief**: Does it solve the stated problem for the stated audience in the stated medium?
2. **Concept**: Is there a clear idea, or is it only decoration?
3. **Hierarchy**: Squint test - is the first read obvious? Is there a clear 1st, 2nd, 3rd?
4. **Contrast**: Are differences decisive, or timid?
5. **Alignment and grid**: Does everything align to the grid? Any accidental near-misalignments?
6. **Spacing**: Is spacing consistent and from the system? Does proximity group correctly?
7. **Typography**: 2 typefaces max? Good line length, leading, rag? Correct punctuation characters?
8. **Color**: Works in grayscale? Accent used sparingly and meaningfully? Contrast passes WCAG?
9. **Consistency**: Same treatments for same roles everywhere?
10. **Simplicity**: What can be removed without loss?
11. **Real-size test**: Checked at actual size, distance, and device (logo small, poster far, UI on mobile)?
12. **Accessibility and ergonomics**: Legible, color-independent meaning, keyboard/focus, touch targets, reduced motion?
13. **Production**: Correct color mode, resolution, bleed, formats, fonts?

When reporting a critique, list issues by severity (critical / important / polish), each with the principle violated and a concrete fix.
