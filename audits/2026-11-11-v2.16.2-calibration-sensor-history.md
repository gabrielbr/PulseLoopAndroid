# Audit: calibration on BP/glucose detail, 0x55 sensor history (2.16.2)

Date: 2026-11-11 · PR: see the PR linking this file · Auditor: Claude Code (the four skills applied by hand from their SKILL.md files)

## Scope

- **BP and glucose detail screens: a Calibration card.** It sits under the amber "estimate" card,
  says what the estimate is calibrated against (or that it isn't), and has a tonal "Calibrate"
  button to Settings → Calibration. Before this, calibration was reachable only from Settings.
- **Jring offline sensor history (`0x55`).** BP, stress, sugar and HRV every 15 minutes, imported
  per day after heart rate, with offline SpO₂ (`0x40`) and skin temperature (`0x39`). They feed
  the existing charts. A ring that sets the temperature bit gets the existing temperature card;
  there is no new screen.
- **Bug fix.** Today's view model added the cuff reference to BP readings. No screen read those
  fields.
- Sugar stays visible (owner's decision).
