# Audit: every button 52dp, through one PulseButton (v2.11.57)

Date: 2026-11-04 · PR: see below · Auditor: Claude

## Scope

Closes open item P2-1 from `2026-11-04-v2.11.56-design-system.md`. The design system says buttons
are at least 52dp tall (DESIGN.md "Buttons"; the `button` size token, 52px). PulseLoop's buttons were
Material3 defaults: 40dp tall, 48dp touch target.

- New `ui/components/PulseButton.kt`: one composable, `PulseButton(style, onClick, …)`, styles
  Filled / Tonal / Outlined / Text over the matching Material3 buttons. It sets
  `heightIn(min = 52.dp)` and the system's 97% press scale (`pressScale`), and keeps each style's
  Material defaults for colours, border, shape and padding unless a caller passes its own.
- 247 calls in 32 files moved onto it (Button 53, OutlinedButton 54, FilledTonalButton 1,
  TextButton 136, plus 3 fully qualified calls). Fixed `.height(48|52|56.dp)` and redundant
  `heightIn(min = 48.dp)` on buttons were removed: the height is PulseButton's now, as a minimum.
- `PulseButtonTest` fails on any direct Material button call (Glance widgets exempt) and pins 52dp.
- No colour, radius or spacing token changed. `drift.py --pulseloop`: 0 differences.
